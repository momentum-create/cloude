## 2. NotAHotel青島 — 分与に含める理由と扱い

### なぜ含めるか
- 当方が**個人保有を確認**している（法人名義ではない、という当方認識）。
- 本件同居宅だけが清算対象、という相手の狭め方を防ぐ。
- 株式より**不動産として評価・差押・保全のイメージが付きやすい**（権利形態による）。

### 分与上の論点（これから固める）
| 論点 | 意味 |
|---|---|
| **権利の中身** | 所有権（区分所有等）か、利用権・会員権・SPC持分か。NotAHotel系は商品設計が特殊なことがあり、**登記・契約書で確定**する |
| **取得時期** | 内縁開始前＝特有主張されやすい／期間中＝対象性が強い／期間中のローン返済・維持費＝増加分・寄与の材料 |
| **対価の出処** | 個人資金か、会社資金の流出か（後者は別途不当利得・役員貸付の話にもなり得る） |
| **基準時評価** | 別居時（又は審判時運用）の時価・残債・売却制約 |
| **特有との切り分け** | 相手は「投資用・特有」と言う可能性大。当方は「同居期間の資産形成の一部／協働で維持可能になった余裕資産」と位置づける |

### 見込みの置き方（株式との対比）
| | NotAHotel青島 | 法人株式 |
|---|---|---|
| 対象リスト | **必ず載せる** | 載せる |
| 額の見積 | 登記・契約・残債が取れれば株式より早い | 決算開示が必要で遅い |
| 相手の抵抗 | 「特有・投資」で外そうとする | 「特有・事業継続」で外そうとする |
| 現実の取り方 | 金銭清算に算入、または保全の対象候補 | 金銭清算・交渉カード |

**円額はまだ出さない。** 「含める／開示対象にする」が今の正解。

## 3. 清算イメージ（構造だけ）

```
分与の土俵（イメージ）
├─ 本件建物正味（時価 − 残債）……主戦場
├─ NotAHotel青島正味（評価 − 残債・売却制約）……個人不動産として加算
├─ 株式の「内縁期間増加分」……開示後
└─ 預貯金等……開示後
        ↓
   × 寄与割合（原則二分の一に寄りつつ、特有・寄与で調整）
        ↓
   金銭支払い／解決金／居住条件とパッケージ
```

株式だけで見ると不透明だったが、**青島を足すと「個人資産の厚み」が交渉で語れる**。  
ただし地裁の7/31書面では、評価額断定はせず、「本件以外にも個人不動産（NotAHotel青島）を有する」程度の事実指摘に留めるか、家裁申立側に厚く書くかは村上先生確認。

## 5. 家裁・財産分与申立に書く資産一覧（案）

申立時点で分かっている相手資産として、少なくとも次を列挙する。

1. 本件建物（東京・同居宅）およびその住宅ローン  
2. **宮崎・青島所在の NotAHotel 物件（原告個人名義で保有を確認）**  
3. 原告が発行済株式を有する会社（商号・本店は登記で特定）の株式  
4. 預貯金その他（開示を求める）

評価額は「不明・開示後に主張」でよい。
